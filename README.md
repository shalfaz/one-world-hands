### 📌 Overview
**One World Hands** is a social-impact NGO and donation management platform built to bridge donors, volunteers, and humanitarian initiatives with transparency and accessibility.

### ✨ Key Features
- **Dynamic Fundraising Campaigns:** Real-time campaign progress tracking, impact stories, and structured donation workflows.
- **Role-Based Dashboards:** Separate authenticated portals for **Admins** (campaign creation, donor & fund management) and **Volunteers** (event coordination and field activity updates).
- **Bilingual Accessibility (`EN / BN`):** Seamless language switching between English and Bengali to maximize community reach.

### 🛠️ Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend & Auth:** Next.js API Routes, MongoDB, NextAuth.js, Vercel
